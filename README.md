#  Kinyarwanda Voice Assistant (Kinyawhisper)

A mini voice assistant that listens to you speak in **Kinyarwanda**, understands your question, and responds using synthesized speech.

   Record voice →  Transcribe & understand → 🗣️ Speak the reply.

---

## 🛠 Features

- 🎙️ Voice input using microphone
- 🧠 Kinyarwanda speech-to-text with Google Speech Recognition
- 💬 Simple Q&A matching with custom responses
- 🔊 Voice output using gTTS and pygame

---
